# React Tooling Defaults

- Prefer Vite, React, TypeScript, Bun, Oxlint, and the shared lint config.
- Start with React state, browser APIs, and plain domain functions; add routing, server caching, or external state when required.
- Follow `css-layout`. Prefer Panda CSS for typed styles, tokens, or recipes in non-trivial apps; use plain CSS for tiny apps. Do not default to a component framework.
- Provide quality scripts, tests when warranted, and `check:slop` for agent-edited projects. Document Panda code generation, ignored output, and private-data boundaries.
