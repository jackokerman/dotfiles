# Priority Order

Run `godspeed-gtd smart-list priority --label <label-name>` to resolve the category label and matching active-backlog smart list and return its first active top-level root. Pass `--name <smart-list-name>` only to disambiguate multiple matching smart lists. Treat the returned root and GTD state as authoritative; the CLI owns numeric ordinal comparison, creation-time fallback, and nested-task exclusion. If it returns a null root, no active category root exists.

After selecting the root, fetch its notes with `task get`; then make a filtered source-list pass sorted by numeric `order_index` to retain only that root and its following descendants up to the next top-level task. Fetch the selected child's full notes with `task get`. Never emit raw source-list responses into context or rely on API response order as persisted source-list order.

For a repository or domain request with no matching category label and smart list, use a bounded fallback instead of dumping the source lists. Filter each response before output to top-level tasks whose title or notes explicitly mention the supplied repository or domain, and project only `id`, `title`, `list_id`, `created_at`, and `order_index`. Treat a repository name embedded in another repository basename, such as `dotfiles` inside `other-dotfiles`, as a different repository unless an exact path proves otherwise. Rank Next Actions ahead of Someday and then by numeric `order_index`; fetch full notes only for the selected task. State that this is source-list priority without a category ordinal. Do not widen the match semantically or emit unrelated tasks.

For repository next-work requests, compare the selected root's stated outcome with bounded current-repository evidence before returning it as actionable. Evaluate one candidate at a time and stop after finding the first current root; do not bulk-fetch full notes for every match. If the evidence proves an outcome is already satisfied, identify the task as stale, continue to the next ranked candidate, and do not complete or clear anything without approval.
